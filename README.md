# Thanasis Liagkas — Portfolio

Personal software developer portfolio.

## Deploy with GitHub Pages
1. Create a public repository named `thanasisliaggas04-bot.github.io`
2. Upload `index.html`, `style.css`, and `script.js` to the repository root.
3. Open **Settings → Pages**.
4. Under **Build and deployment**, choose **Deploy from a branch**.
5. Select **main** and **/(root)**, then Save.

Your portfolio will be available at:
`https://thanasisliaggas04-bot.github.io`

> Note: The Forecast project card currently points to `/forecast`. Create that repository when the source project is ready to publish.
